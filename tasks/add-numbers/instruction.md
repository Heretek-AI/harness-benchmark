# Task: Add Two Numbers

Write a Python function `add(a, b)` that returns the sum of two numbers.

## Requirements

- The function must accept two arguments `a` and `b`
- It must return their sum (not print it)
- Save the function in a file called `solution.py`

## Example

```python
add(2, 3)  # returns 5
add(-1, 1)  # returns 0
```
