# Task: Sort a List

Write a Python function `sort_list(items)` that returns a new list with the elements sorted in ascending order.

## Requirements

- The function must accept a list of comparable items
- It must return a new sorted list (do not modify the input)
- Save the function in a file called `solution.py`

## Example

```python
sort_list([3, 1, 4, 1, 5])  # returns [1, 1, 3, 4, 5]
sort_list([])  # returns []
sort_list(["b", "a", "c"])  # returns ["a", "b", "c"]
```
